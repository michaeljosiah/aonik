## Quick orientation

- **Foundations** — `colors_and_type.css` (all tokens + semantic roles). Includes warm palette (signature), dark hero stops, status colors, type scale, spacing, radii, shadows, gradients.
- **Assets** — `assets/` (demo_profile.jpg, simi.png, setup-hero.png, spending-empty-hero.png, budget-hero.png, mba_logo.png, flags/, illustrations/, slider-img-*.png). No official wordmark file yet.
- **UI kit** — `ui_kits/mobile/` — React components + full interactive prototype (Home, Pay, Spending, Chat/Simi, Transaction detail).
- **Previews** — `preview/` — individual token cards used by the Design System tab.

## Brand in one line
Warm, grounded, intimate. Orange `#F37920` + ink on cream; dark brown heroes for money views. Open Sans. No emoji, no corporate blues. Uppercase button labels, 4px radius, Material Rounded icons.
