# Pull Request Process

## Expectations

- Keep changes focused and explain the motivation.
- Include test coverage or explain why it’s not applicable.
- Update documentation when behavior/config changes.

## Checklist

- Build passes: `dotnet build Aonik.sln`
- Tests run (as applicable): `dotnet test Aonik.sln`
- No secrets committed
