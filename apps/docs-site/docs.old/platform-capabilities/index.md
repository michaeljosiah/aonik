## What this section will cover

One page per platform capability, covering its entities, lifecycle, configuration, and the agent tools attached to it:

- **Identity** — Tenants, Party & Profile, Users, Roles & Permissions
- **Money movement** — Orders, Ledger, Payments, Billing
- **Reference data** — Catalog (billers, services, countries, currencies), Autonumbering
- **Pricing** — Pricing & FX, Partners
- **Personal finance** — Personal accounts, transactions, Financial Life Graph, Household
- **Compliance** — Cases, documents, audit log
- **Notifications** — Templates, bindings, delivery channels
- **CMS** — Content Blocks
- **Settings** — Global, tenant, user (with override rules)

Each capability page links to the [API Reference](/api/aonik-api) for the corresponding endpoints.
