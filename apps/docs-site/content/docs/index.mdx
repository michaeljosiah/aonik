Aonik is the open-core platform for building **AI-native financial products**. You self-host it, plug in your identity provider and third-party integrations, and ship the product your customers need on top.

These docs are split into three audience tracks. Pick the one that matches what you are trying to do.

<Cards>

<Card title="Operate" href="/docs/operate" description="You are the engineer running an Aonik deployment. Install the platform, configure identity and integrations, monitor jobs, and contribute back to the codebase." />

<Card title="Build with the API" href="/docs/api" description="You are integrating with a hosted Aonik tenant from your own application. Get a bearer token, call endpoints, receive webhooks." />

<Card title="Tenant admin" href="/docs/tenant-admin" description="You manage a single Aonik tenant from the Admin UI without writing code. Settings, catalogue, users, compliance, billing." />

</Cards>

## A note on this rewrite

These docs are being delivered in phases. The Operate track is the most complete today (Quickstart, Install & Configure, CLI). The API track has the conceptual primer (Auth, Webhooks, Errors) — the auto-generated endpoint reference is being wired in next. The Tenant admin track currently has landing copy with screen-by-screen walkthroughs being captured against the seeded demo tenant.

If a page is missing or wrong, the canonical source of truth is the codebase itself — `apps/docs-site/docs.old/` keeps the pre-rewrite material for reference until each section ships.
