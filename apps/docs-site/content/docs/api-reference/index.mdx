## What this section will cover

When this section lands you'll get an auto-generated reference page for every endpoint Aonik exposes, grouped by tag:

- **Orders** — list, create, retrieve, submit, cancel, line-item CRUD
- **Payments** — create intent, retrieve, capture, cancel
- **Billing** — create invoice, get invoice, issue, cancel, mark paid, line operations, discounts
- **Ledger** — list/create ledgers, list/create accounts, list/add journal entries
- **Catalog** — countries, currencies, billers, biller categories, services
- **Pricing** — FX quotes, pricing quotes
- **Partners** — list, create, get, update, delete
- **Identity** — token, current user, profile, password reset, email verification
- **Registration** — register, onboarding status
- **Tenants** — CRUD operations + activate/deactivate/provision/bootstrap
- **Users** — list, invite, get, activate/deactivate, update roles
- **Roles** — CRUD + permissions management
- **Compliance** — documents management
- **AI** — chat threads, agents, workflows
- **CMS** — content blocks
