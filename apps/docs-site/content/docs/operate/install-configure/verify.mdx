title: Verify the install
description: A short end-to-end smoke test that proves the platform is correctly installed, the tenant exists, and every resource is reachable. Designed to be executed verbatim by a human or an AI agent.
---

By the time you reach this page you should have a running [Aspire stack](/docs/operate/install-configure/run-with-aspire) and a [bootstrapped tenant](/docs/operate/install-configure/bootstrap-tenant). This page runs a single script that asserts every claim at once.

The script exits with code `0` only if every assertion passes. Any failure prints `❌ <assertion>` to stderr and exits with code `1` — perfect for CI or an AI agent.

## Before you start

- The AppHost is running (`dotnet run --project src/Aonik.AppHost` is still active in a terminal).
- The bootstrap call has completed and `/bootstrap/status` reports `completed`.
- You know the email you used for `ownerEmail`.

## The verification script

Save this as `scripts/verify-install.ps1` (or run it inline). It performs nine assertions covering every surface a fresh install should expose.

```powershell
#requires -Version 7
param(
  [string]$ApiUrl       = 'https://localhost:5001',
  [string]$AdminUrl     = 'http://localhost:5173',
  [string]$QdrantUrl    = 'http://localhost:6333',
  [string]$KeycloakUrl  = 'http://localhost:8080',
  [string]$OwnerEmail   = 'you@example.com'
)

$ErrorActionPreference = 'Stop'
$failures = @()

function Assert($name, $scriptblock) {
  try {
    & $scriptblock
    Write-Host "✅ $name" -ForegroundColor Green
  } catch {
    Write-Host "❌ $name — $_" -ForegroundColor Red
    $script:failures += $name
  }
}

# 1. API process is reachable
Assert 'API /health is Healthy' {
  $h = curl.exe --insecure --silent --max-time 5 "$ApiUrl/health" | ConvertFrom-Json
  if ($h.Status -ne 'Healthy') { throw "Status: $($h.Status)" }
}

# 2. Scalar API reference is served
Assert 'API /scalar serves an HTML page' {
  $code = curl.exe --insecure --silent --output $null --write-out '%{http_code}' "$ApiUrl/scalar"
  if ($code -ne '200') { throw "HTTP $code" }
}

# 3. Bootstrap is completed
Assert 'Bootstrap status is completed' {
  $s = curl.exe --insecure --silent --max-time 5 "$ApiUrl/bootstrap/status" | ConvertFrom-Json
  if ($s.state -ne 'completed') { throw "state: $($s.state)" }
}

# 4. Exactly one tenant exists
Assert 'Exactly one tenant exists' {
  $count = sqlcmd -S '(localdb)\MSSQLLocalDB' -d AonikDb -h -1 -Q 'SET NOCOUNT ON; SELECT COUNT(*) FROM AnkTenants' |
    ForEach-Object { $_.Trim() } |
    Where-Object { $_ -match '^\d+$' } |
    Select-Object -First 1
  if ([int]$count -ne 1) { throw "tenant count: $count" }
}

# 5. Owner user exists
Assert 'Owner user exists with PlatformAdmin role' {
  $rows = sqlcmd -S '(localdb)\MSSQLLocalDB' -d AonikDb -h -1 -Q @"
SET NOCOUNT ON;
SELECT r.Name
FROM AnkUserRoles ur
JOIN AnkUsers u ON u.Id = ur.UserId
JOIN AnkRoles r ON r.Id = ur.RoleId
WHERE u.Email = '$OwnerEmail';
"@
  $rolesFound = $rows | ForEach-Object { $_.Trim() } | Where-Object { $_ -in 'PlatformAdmin','TenantAdmin' } | Sort-Object -Unique
  if ($rolesFound.Count -lt 2) { throw "roles found: $($rolesFound -join ',')" }
}

# 6. Admin UI dev server is reachable
Assert 'Admin UI returns 200' {
  $code = curl.exe --silent --output $null --write-out '%{http_code}' "$AdminUrl/"
  if ($code -ne '200') { throw "HTTP $code" }
}

# 7. Qdrant readiness probe
Assert 'Qdrant is ready' {
  $body = curl.exe --silent --max-time 5 "$QdrantUrl/readyz"
  if ($body -notmatch 'all shards are ready') { throw "readyz: $body" }
}

# 8. Qdrant container is healthy
Assert 'Qdrant container is healthy' {
  $row = docker ps --filter 'ancestor=qdrant/qdrant' --format '{{.Status}}' | Select-Object -First 1
  if (-not $row -or $row -notmatch 'Up ') { throw "container status: $row" }
}

# 9. Public OpenAPI document is served
Assert 'OpenAPI document is served' {
  $body = curl.exe --insecure --silent --max-time 5 "$ApiUrl/openapi/v1.json"
  if ($body -notmatch '"openapi"') { throw "no openapi field in response" }
}

# 10. (Keycloak only) Realm discovery document is served
if ($env:AONIK_AUTH_PROVIDER -eq 'Keycloak') {
  Assert 'Keycloak realm OIDC discovery is served' {
    $body = curl.exe --silent --max-time 5 "$KeycloakUrl/realms/aonik/.well-known/openid-configuration"
    if ($body -notmatch '"issuer"\s*:\s*"http://localhost:8080/realms/aonik"') {
      throw "discovery document missing or wrong issuer"
    }
  }
}

if ($failures.Count -gt 0) {
  Write-Host ''
  Write-Host "Verification FAILED. Failures: $($failures -join ', ')" -ForegroundColor Red
  exit 1
}

Write-Host ''
Write-Host 'Install verified. The Aonik platform is healthy and a tenant is in place.' -ForegroundColor Green
Write-Host 'Next step: wire identity in /docs/operate/identity-access so the owner can sign in.' -ForegroundColor Cyan
```

## Running the script

**Inline (one-shot):**

Save the block above to a file, then:

```powershell
# Non-Keycloak setups
.\scripts\verify-install.ps1 -OwnerEmail 'you@example.com'

# Keycloak fastest-path setup (matches the run-with-aspire step 2.5 walkthrough)
.\scripts\verify-install.ps1 -OwnerEmail 'admin@aonik.local'
```

**Expected final output (one of two):**

Pass:

```
✅ API /health is Healthy
✅ API /scalar serves an HTML page
✅ Bootstrap status is completed
✅ Exactly one tenant exists
✅ Owner user exists with PlatformAdmin role
✅ Admin UI returns 200
✅ Qdrant is ready
✅ Qdrant container is healthy
✅ OpenAPI document is served

Install verified. The Aonik platform is healthy and a tenant is in place.
Next step: wire identity in /docs/operate/identity-access so the owner can sign in.
```

Fail (example):

```
✅ API /health is Healthy
❌ Bootstrap status is completed — state: ready
...

Verification FAILED. Failures: Bootstrap status is completed, Exactly one tenant exists, Owner user exists with PlatformAdmin role
```

## Reading the failure modes

| Failure                                | Most likely cause                                                                  | Where to go                                                                                          |
| -------------------------------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `API /health is Healthy`               | API not running or LocalDB unreachable                                             | [Run with Aspire — Troubleshooting](/docs/operate/install-configure/run-with-aspire#troubleshooting)         |
| `Bootstrap status is completed`        | Bootstrap call has not been made yet                                               | [Bootstrap your first tenant](/docs/operate/install-configure/bootstrap-tenant)                              |
| `Exactly one tenant exists`            | Database was reset after bootstrap, or migrations failed                           | Re-run [Bootstrap your first tenant](/docs/operate/install-configure/bootstrap-tenant)                       |
| `Owner user exists with PlatformAdmin` | The email passed to `verify-install.ps1` doesn't match the bootstrap `ownerEmail`  | Re-run with `-OwnerEmail '<the-email-you-used>'`                                                     |
| `Admin UI returns 200`                 | Vite dev server crashed or `npm install` failed for `src/Aonik.AdminUi`            | Check the `adminui` row in the Aspire dashboard for logs                                             |
| `Qdrant is ready` / container healthy  | Docker Desktop stopped, or the Qdrant volume is corrupt                            | Restart Docker Desktop; `docker rm` the container and let Aspire recreate it                         |
| `OpenAPI document is served`           | The API is running but the OpenAPI middleware is disabled                          | Confirm `OpenApi:Enabled` is true in `appsettings.Development.json` (the default)                    |
