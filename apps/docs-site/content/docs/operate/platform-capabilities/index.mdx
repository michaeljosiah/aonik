## What this section will cover

One page per platform capability, covering its entities, lifecycle, configuration, and the agent tools attached to it:

- **AONIK Core** - Identity, tenancy, AI routing, agents, memory, workflows, tasks, approvals, audit, notifications, settings, shared human primitives
- **Finance** - Orders, Ledger, Payments, Billing, Pricing & FX, Partners, Catalog
- **Personal Finance** - Personal accounts, transactions, Financial Life Graph, Household, bills, subscriptions, budgets, goals, customer insights
- **Trust & Governance** - Compliance cases, documents, risk policies, audit log, approval workflows
- **Reference data** - Catalog (billers, services, countries, currencies), Autonumbering
- **CMS** - Content Blocks

Each capability page links to the [API Reference](/docs/api) for the corresponding endpoints.
