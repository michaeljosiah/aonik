Long-form guides to the platform features that support Arke Studio and Arke Kids,
written for someone who wants to understand not just what each feature does but
why it is built the way it is — the flows, the libraries chosen, and the race
conditions each guarded statement closes.

These are full-page documents in the same style as the platform's specifications,
so they open outside the docs chrome. Each links back to the specification it
implements, and those links resolve here too — the specifications and ADRs are
served alongside the guides.

## Where these come from

The guides live in the repository at `docs/features/` and are copied into this
site at build time, together with the folders they reference:

- `/specifications/` — the numbered platform specifications (HTML)
- `/decisions/` — architecture decision records (raw markdown)
- `/architecture/`, `/observability/`, `/runbooks/` — supporting notes

The canonical source of truth is the repository; this site republishes it.
