## What this page will cover

When complete, this page will document the full inbound webhook contract:

- The event catalog (`invoice.issued`, `payment.captured`, `proposal.raised`, `tenant.provisioned`, `ai.run.completed`, etc.)
- The envelope shape (id, type, occurredUtc, tenantId, data)
- How to register a destination URL via the API or the Admin UI
- The signing scheme — header name, algorithm, payload, time-window verification
- The retry policy and dead-letter behaviour
- How to replay an individual event from the Admin UI
- Local development with `webhook.site` and ngrok

## What works today

The platform supports outbound webhooks for the events listed in `Aonik.Platform.Services.Notifications`. The Admin UI exposes destination registration on the **Notifications → Webhooks** panel. Until this page is finished, browse the Admin UI directly to see the live schemas.
