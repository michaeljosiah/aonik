## The five steps

<Steps>

<Step>

### 1. Install prerequisites

You need Docker Desktop, the .NET 10 SDK, SQL Server LocalDB, Node.js 18+, PowerShell 7, and Git.

Run the one-shot check script at the bottom of [Prerequisites](/docs/install-configure/prerequisites). It exits non-zero on the first missing tool and tells you exactly which one.

</Step>

<Step>

### 2. Clone the repo

```powershell
git clone https://github.com/michaeljosiah/aonik.git
Set-Location aonik
```

</Step>

<Step>

### 3. Configure the bootstrap secret

```powershell
dotnet user-secrets --project src/Aonik.Api set Bootstrap:Enabled true
$secret = [guid]::NewGuid().ToString()
dotnet user-secrets --project src/Aonik.Api set Bootstrap:SetupSecret $secret
Write-Host "Bootstrap secret: $secret"
```

Save the GUID — you will pass it to `/bootstrap` in step 5.

</Step>

<Step>

### 4. Start the Aspire orchestrator

```powershell
dotnet run --project src/Aonik.AppHost
```

Aspire pulls the **Qdrant** container via Docker Desktop and starts the **API**, the **Worker**, and the **Admin UI** Vite dev server. The Aspire dashboard opens at `https://localhost:21183` — wait until every row turns green.

Full detail (URLs, what each resource is, common failures): [Run with Aspire](/docs/install-configure/run-with-aspire).

</Step>

<Step>

### 5. Bootstrap your first tenant

In a **second** terminal (leave the AppHost running):

```powershell
$secretLine = dotnet user-secrets --project src/Aonik.Api list |
  Select-String -Pattern '^Bootstrap:SetupSecret = '
$secret = ($secretLine -split ' = ', 2)[1]

$payload = @{
  setupSecret      = $secret
  ownerEmail       = 'you@example.com'
  ownerDisplayName = 'Platform Admin'
} | ConvertTo-Json

curl.exe --insecure --silent -X POST https://localhost:5001/bootstrap `
  -H 'Content-Type: application/json' `
  -d $payload | ConvertFrom-Json | Format-List
```

This creates the initial tenant, the owner user, and the `PlatformAdmin` + `TenantAdmin` role assignments. Calling `/bootstrap` again returns **409 Conflict** — it's one-time per database.

Full detail (status pre-flight, failure modes, dev database reset): [Bootstrap your first tenant](/docs/install-configure/bootstrap-tenant).

</Step>

</Steps>

## Verify everything works

Run the verification script described in [Verify the install](/docs/install-configure/verify). It performs nine assertions in one go — API healthy, Scalar reference served, bootstrap completed, one tenant present, owner has admin roles, Admin UI reachable, Qdrant ready, container healthy, OpenAPI document served — and exits with code `0` only if all pass.
