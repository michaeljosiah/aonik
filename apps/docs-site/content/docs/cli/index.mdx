The Aonik CLI is a headless command surface. It is invoked by agent harnesses (which bring their own chat interface) and run directly by human operators for explicit operational tasks. There is no built-in chat or interactive shell.

## What this section will cover

A page per command surface:

- **Install** — building or installing `Aonik.Cli`
- **Authenticate** — `auth login` and `auth logout`
- **Agents** — `agent list`, `agent run <prompt>` for one-shot orchestrator calls, `agent stream` for AG-UI events, `agent threads` / `agent thread <id>` for thread inspection
- **Approvals** — `approvals list`, `approvals approve <id>`, `approvals reject <id>`
- **Operations** — `ops jobs`, `ops ledger`, `ops invoices`, `ops payments`, `ops workflow`
- **Output modes** — JSON, NDJSON, Text
