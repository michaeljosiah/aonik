# 007.cards-vault

## Objective
Provide card vault endpoints for saved payment methods.

## Scope
- `POST /payments/methods/setup-intent`
- `GET /payments/methods`
- `GET /payments/methods/{paymentMethodId}`
- `POST /payments/methods`
- `DELETE /payments/methods/{paymentMethodId}`
- `GET /payments/methods/active`

## Requirements
- Setup intent returns clientSecret and payment method types.
- List endpoints return masked card details (last4, brand, expiry).
- Save endpoint links payment method to customer/party.
- Delete endpoint removes payment method from customer.
- Vault stores tokens only; no PCI data persisted in Aonik.

## Application Services
- PaymentMethodService.CreateSetupIntentAsync
- PaymentMethodService.ListAsync
- PaymentMethodService.GetAsync
- PaymentMethodService.SaveAsync
- PaymentMethodService.DeleteAsync
- PaymentMethodService.ListActiveAsync

## Acceptance Criteria
- No raw PAN or PCI data stored in Aonik.
- Payment methods are tenant scoped.
- Active list aligns with gateway availability.
