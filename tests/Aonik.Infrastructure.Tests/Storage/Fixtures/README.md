`rainbow.heic` is the 451 × 461 real HEIC test image from libheif:

https://github.com/strukturag/libheif/blob/178b11afc84a43da8b57e17b40ce77dedb5bb414/tests/data/rainbow-451x461.heic

The upstream LGPL license is retained in `libheif-COPYING`. The image is used only
to verify actual HEIC decoding in the Windows and Linux test runtimes. It is not
customer data. No production scanner, storage or email service is used by tests.
