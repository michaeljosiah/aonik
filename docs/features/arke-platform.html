The one-paragraph version

Arke Studio is a desktop authoring product where nothing enters the record without a human accepting it. Arke Kids is a child-facing companion built on the same worlds. AONIK gives both of them their platform layer: a workspace is a versioned tree of files (an Arke world is a workspace of kind world); sync moves those trees between machines without ever merging anything automatically; an entitlement token lets the desktop app prove what was paid for while offline; and the content safety gate sits between every AI generation and every child, failing closed. The platform stores containers, revisions and bytes — it never opens a file and it never learns what a "sheet" or a "canon entry" means. That seam is deliberate and tested.

The rule that shapes everything: modules never reference each other. They reference Aonik.SharedKernel and communicate through its contracts. When the safety gate needs a child's age band, it asks ISafetyBandReader — a SharedKernel interface Platform implements — rather than referencing Platform. An architecture test fails the build if Aonik.Workspaces ever references anything except SharedKernel.

Why two test lanes matter here Several core guarantees are single guarded SQL statements — a compare-and-swap on the workspace head, the sweeper's deletion claim, the entitlement key's retirement bound. The InMemory provider does not implement ExecuteUpdateAsync at all, so a test there could only assert the shape of the code, not the property. Those tests run against SQL Server LocalDB (tests/Aonik.Database.Tests), where the statement is real and the filtered unique indexes actually enforce. This lane has caught real bugs the InMemory lane structurally could not — including an IReadOnlySet.Contains that the relational provider refuses to translate.

Design principles that repeat across every page

1. Fail closed, and make the safe state the default state

A classifier outage blocks content rather than passing it. An unknown age band is treated as the youngest, not as an adult. A missing entitlement key refuses to issue rather than inventing one. An empty custodian list means preserved material is unreachable, not reachable by whoever has an admin claim. In every case the question was: which wrong default ends badly? — and the design takes the other one.

2. Compare-and-swap by data, not locks by timing

Three separate features needed to stop two concurrent operations trampling each other: advancing a workspace head, sweeping an unreferenced blob, and retiring a signing key. All three use the same shape — a single guarded UPDATE whose WHERE clause states the invariant, where zero rows affected means "you lost, re-read and reclassify". No locks, because a lock serialises everyone to protect against a rare race; the CAS costs nothing when there is no contention.

3. Enforcement is a type, not a convention

Content cannot be delivered to a child without a ContentDeliveryPermit, and only the safety gate can construct one — the constructor is internal. A delivery path takes a permit rather than a boolean, so "did you remember to check?" is a compile error rather than a code-review hope. The same pattern guards playable narration (the permit must name the exact audio it covers) and mirrors Spec 032's rule that an unclassified mutating AI tool fails at build time.

4. A name is not an authorisation

A content hash names bytes; it must never grant them. A grant's existence is not the same as what it permits. A plan name is not a feature list. Wherever a caller could present an identifier and receive access, the platform checks a separate, explicit record: BlobPossession for hashes, AccessLevel for grants, resolved feat/lim claims for plans.

5. The platform never reads meaning

TermsJson on a share grant is stored and returned verbatim — the product defines what a "co-author" is. Workspace files are bytes with hashes — the platform never opens one. Divergent revisions are resolved by a human through the product's accept gate — the platform records which of three outcomes they chose and decides nothing. This is what lets one platform serve Payabo, Arke and future products without embedding any product's vocabulary.
