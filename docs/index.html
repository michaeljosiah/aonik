02Getting Started

Project structure at a glance#

AONIK is organized as a module-first modular monolith. Each module owns its vertical slice: entities, services, endpoints, and persistence configuration.

Root directory layouttext
aonik/
├── src/
│   ├── Aonik.SharedKernel/        Shared types, interfaces, events
│   ├── Aonik.Platform/            Core platform module
│   ├── Aonik.Finance/             Finance domain module
│   ├── Aonik.PersonalFinance/     Personal finance module
│   ├── Aonik.Ai/                  AI module (providers, models, prompts)
│   ├── Aonik.Agents/              Agents module (orchestration, proposals)
│   ├── Aonik.Application/         Shared application abstractions
│   ├── Aonik.Infrastructure/      EF Core migrations, adapters
│   ├── Aonik.Api/                 FastEndpoints HTTP API
│   ├── Aonik.Worker/              Background jobs (Quartz)
│   ├── Aonik.AppHost/             .NET Aspire orchestrator
│   ├── Aonik.Migrator/            Database migration runner
│   ├── Aonik.Finance.Mcp/         Finance MCP server
│   └── Aonik.Platform.Mcp/        Platform MCP server
├── tests/                          Test projects
├── docs/                           Documentation (this directory)
├── AGENTS.md                       Coding guidelines
├── CHANGELOG.md                    Version history
├── README.md                       Project overview
└── Aonik.sln                       Solution file
03Getting Started

Common development tasks#

Quick reference for frequently-used commands:

Build commands

Building the solutionbash
# Build entire solution
dotnet build Aonik.sln

# Build specific project
dotnet build src/Aonik.Api
dotnet build src/Aonik.Application

# Clean build
dotnet clean Aonik.sln && dotnet build Aonik.sln

Test commands

Running testsbash
# Run all tests
dotnet test Aonik.sln

# Run tests for a specific project
dotnet test tests/Aonik.Application.Tests
dotnet test tests/Aonik.Api.Tests

# Run a single test by filter
dotnet test --filter "DisplayName~CreateInvoice"

# Run tests with verbose output
dotnet test --logger "console;verbosity=detailed"

Database commands

Entity Framework operationsbash
# Create migration (ALWAYS against AonikDbContext)
dotnet ef migrations add <MigrationName> \
  --project src/Aonik.Infrastructure \
  --startup-project src/Aonik.Api

# Update database
dotnet ef database update \
  --project src/Aonik.Infrastructure \
  --startup-project src/Aonik.Api

# Remove last migration
dotnet ef migrations remove \
  --project src/Aonik.Infrastructure \
  --startup-project src/Aonik.Api

Running the API

API executionbash
# Run with Aspire
dotnet run --project src/Aonik.AppHost

# Run API directly
dotnet run --project src/Aonik.Api
# API runs on https://localhost:5001 with Swagger UI at /swagger

# Initialize database
dotnet run --project src/Aonik.Migrator
Critical: Migrations

All EF Core migrations must be generated against AonikDbContext only. Never generate migrations against module-scoped DbContexts (PlatformDbContext, FinanceDbContext, etc.). See AGENTS.md §8 for full details.
